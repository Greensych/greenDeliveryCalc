# 🐘 Зелёный Слоник · Delivery Calc

Калькулятор порогов корзины (`min_cart_amount`) и стоимости доставки по шагам.

Сделано с особым настроением.

## Запуск

Просто открой `index.html` или залей на GitHub Pages.

## Параметры

| Параметр | Описание |
|----------|----------|
| `k_g` | Коэффициент гостя |
| `k_r` | Коэффициент ресторана (по умолчанию 0) |
| `C_cp` | Средний чек |
| `D_0` | Базовая стоимость доставки |

## Формула

```
D_n = D_0 × k_n
C_n = C_cp + [ (k_g + k_r) × C_cp + (D_0 − D_n) ] / 0.17
min_cart = ⌈ C_n / 100 ⌉ × 100   (для k_n < 1, иначе 0)
delivery_price = ⌈ D_n / 10 ⌉ × 10
```

Шаги: `k_n = 1.0 → 0.8 → 0.55 → 0.35`  
bar_percent: `20 / 20 / 25 / 35`

## Пример

При `C_cp = 3277.50`, `D_0 = 540`, `k_g = 0`, `k_r = 0`:

```json
[
  { "bar_percent": 20, "delivery_price": 54000, "min_cart_amount": 0 },
  { "bar_percent": 20, "delivery_price": 44000, "min_cart_amount": 400000 },
  { "bar_percent": 25, "delivery_price": 30000, "min_cart_amount": 480000 },
  { "bar_percent": 35, "delivery_price": 19000, "min_cart_amount": 540000 }
]
```
